# Excel Data Analysis – Task 5

## Project Overview
This project analyzes the Sample Superstore dataset using Microsoft Excel. The analysis demonstrates data organization, Excel formulas, sorting, filtering, PivotTables, and key performance indicators (KPIs).

## Objectives
- Analyze a structured business dataset using Excel
- Calculate important KPIs using Excel formulas
- Create PivotTables to answer business questions
- Identify sales performance across categories and regions
- Summarize key business insights

## Tools Used
- Microsoft Excel
- PivotTables
- Excel Formulas

## Workbook Structure
- Raw_Data – Original dataset kept unchanged
- Working_Formula – KPI calculations and formula-based analysis
- Summary – KPIs, business questions, answers, and key findings
- Pivot_Category – PivotTable analysis

## Key KPIs
- Total Sales: $2,297,200.86
- Total Profit: $286,397.02
- Total Quantity: 37,873
- Average Sales: $229.86
- Total Orders: 5,009

## Key Findings
Technology generated the highest sales among the three categories, while the West region recorded the highest sales among the four regions. The dataset contains approximately $2.30 million in total sales, $286,397.02 in total profit, and 5,009 unique orders.

## Business Questions Answered
1. Which category generated the highest sales?
   - Technology

2. Which region generated the highest sales?
   - West

3. What is the total profit generated?
   - $286,397.02

4. How many unique orders are in the dataset?
   - 5,009
